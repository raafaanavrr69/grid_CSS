# Actividades de CSS Grid

Diez ejercicios de maquetación con CSS Grid. Cada uno parte de la misma
cuadrícula de cinco cajas de colores y prueba una propiedad: desde activar
`display: grid` hasta definir filas y columnas, separaciones y alinear
elementos sueltos con `justify-self` y `align-self`.

## Contenido

- `actividad_1/` … `actividad_10/`: cada ejercicio, con su `index.html` y su `styles.css`.

## Verlo

Abre el `index.html` de cualquier actividad en el navegador.

## Tecnologías

HTML5 y CSS Grid.
